Launching Super Bunny, a Self-Initiated Android Game with Vibrant Design

The Super Bunny project was a self-initiated Android native app, designed as a fun and engaging mobile game. Players guide an animated bunny through obstacles while collecting carrots, using a simple tap-to-jump mechanic.

The project included end-to-end design, from creating UI screens and game assets to developing the animated bunny character and app icon. The visuals were crafted with a playful and vibrant style to appeal to a wide audience. Game elements such as score tracking, “Get Ready” screens, and obstacle interactions were carefully designed to ensure an intuitive and seamless user experience.

This project showcases creativity, character animation, and native app design tailored for Android devices. Explore the full case study to see how a self-initiated project blends design and gameplay into an addictive mobile experience.
